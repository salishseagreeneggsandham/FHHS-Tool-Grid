# FHHS ToolGrid

A professional, parametric Gridfinity organizer system developed by the Friday Harbor High School STEM Program.

## Goals

- Professional-quality toolbox organization
- Standard Gridfinity compatibility
- Optimized for Bambu Lab printers
- Parametric CAD generation
- Easy customization
- Open source

## Current Projects

- DWMT72165 Mechanics Tool Set
- Kobalt 5 Drawer Mobile Cabinet

Drawer Size

31.5" × 15.25"

Gridfinity Layout

19 × 9
